
# PhishInvestig

### Phishing Email Investigation & Threat Intelligence Platform

**Investigate. Correlate. Understand. Defend.**

PhishInvestig is a Python-based SOC email investigation
platform designed to help security analysts examine
suspicious emails, identify phishing indicators, correlate
digital evidence, assess threats and generate structured
investigation reports.

## Key Capabilities

- Email parsing and header investigation
- SPF, DKIM and DMARC analysis
- Suspicious URL and domain extraction
- Attachment metadata and SHA-256 analysis
- Phishing indicator detection
- Evidence correlation
- Explainable risk assessment
- Email investigation timelines
- IOC management
- SOC case management
- MITRE ATT&CK mapping
- PDF and JSON investigation reports

## Technology Stack

- Python 3.12
- Streamlit
- SQLite
- Pytest
- ReportLab
- Git and GitHub

## Project Objective

Demonstrate practical email threat investigation,
digital evidence handling, security analysis and
incident investigation workflows relevant to
SOC Analyst Level 1 responsibilities.

## Security Notice

PhishInvestig is intended for defensive security
analysis using synthetic or appropriately authorized
email samples. It does not execute attachments
or automatically visit suspicious URLs.
